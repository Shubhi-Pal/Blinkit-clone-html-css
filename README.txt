QUICKKART - BLINKIT-INSPIRED GROCERY STORE (HTML + CSS)

How to run:
1. Extract this ZIP.
2. Open the folder in VS Code.
3. Open index.html in your browser (or use Live Server).

Files:
- index.html: webpage structure
- style.css: design and responsive layout
- images/: local SVG product illustrations

Note:
This is a front-end practice project inspired by quick-commerce grocery apps. It is not affiliated with Blinkit.
The ADD buttons are visual only because this version uses HTML and CSS only. JavaScript is needed for a working cart.
